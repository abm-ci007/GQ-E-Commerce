# GQ-E-Commerce

E-commerce project with a Django backend and a React/TypeScript frontend.

## Project structure

- `ABM-Commerce_backend/` — Django API. See [SETUP_SECURITY.md](ABM-Commerce_backend/SETUP_SECURITY.md) and [api_pattern.md](ABM-Commerce_backend/api_pattern.md).
- `ABM-Commerce_frontend/` — React/TypeScript web app. See [BACKEND_DJANGO.md](ABM-Commerce_frontend/BACKEND_DJANGO.md) for backend integration notes.

Local environment files, virtual environments, SQLite databases, and uploaded media are excluded from Git.
